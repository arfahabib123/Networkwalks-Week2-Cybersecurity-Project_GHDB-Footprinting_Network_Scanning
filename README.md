## 🔎 Task 1: GHDB-Based Footprinting

**Objective:** To identify publicly indexed directory listings using advanced Google search operators.

**Google Search Query Used:**

```text
intitle:index.of "parent directory" mathematics pdf
```

**Activities Performed:**
1. Applied the Google search query.
2. Identified publicly indexed directory listings.
3. Collected 10 candidate directory links.
4. Reviewed the potential security risks of publicly exposed directories.

**Key Learnings:**
- Understanding Google search operators.
- Identifying publicly indexed information.
- Understanding the risks of exposed files and directories.

## ⚠️ Security Risks Identified

- **Publicly Exposed Directories:** May reveal files and documents to unauthorized visitors.
- **Sensitive Information Exposure:** Public files may contain confidential information.
- **Unknown Network Devices:** Unrecognized devices may create security risks.
- **Network Visibility:** Monitoring helps identify unexpected devices and network activity.

## 🛡️ Security Recommendations

1. Disable directory browsing when it is not required.
2. Avoid storing sensitive files in publicly accessible directories.
3. Apply appropriate access controls and permissions.
4. Regularly review publicly indexed information.
5. Monitor connected network devices.
6. Investigate unknown devices.
7. Perform network scanning only with proper authorization.
8. Maintain updated network topology diagrams.
